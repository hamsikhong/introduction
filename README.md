# 바이브코딩 교사 포트폴리오

주소: https://hamsikhong.github.io/introduction/

## 파일 구성

| 파일 | 하는 일 | 언제 고치나요 |
|---|---|---|
| `data.json` | 이름, 소개, 작품, 연수 이력 | 내용을 바꿀 때 |
| `style.css` | 색, 글꼴, 크기 | 디자인을 바꿀 때 (맨 위 "디자인 설정"만 보면 돼요) |
| `index.html` | 페이지 뼈대 (섹션 순서, 제목) | 새 칸을 추가하거나 순서를 바꿀 때 |
| `script.js` | data.json을 읽어 화면에 채우는 코드 | 기능을 바꿀 때 |
| `images/` | 작품 스크린샷, QR 이미지 | 사진을 넣을 때 |

## 작품 추가하기

`data.json`의 `"작품"` 목록에 아래 묶음을 하나 더 붙여요. 앞 묶음의 `}` 뒤에 **쉼표(,)** 를 꼭 넣어야 해요.

```json
{
  "종류": "웹사이트",
  "이름": "새 작품 이름",
  "설명": "무엇을 하는 작품인지",
  "주소": "https://...",
  "도구": "Claude · HTML",
  "연도": "2026",
  "스크린샷": "images/새작품.png",
  "QR이미지": ""
}
```

- `종류`는 `웹사이트` 또는 `앱`
- `주소`를 넣으면 QR 코드가 자동으로 만들어져요
- `스크린샷`, `QR이미지`는 `images` 폴더에 사진을 올리고 그 경로를 적어요. 없으면 `""` 로 비워 둬요

## 연수 추가하기

```json
{ "기간": "2026.11", "연수명": "연수 이름", "기관": "기관 이름", "구분": "수강", "시수": 15 }
```

`구분`은 `수강` 또는 `강의`. 총 시수는 자동으로 더해져요.

## 이 페이지 QR

`"사이트주소"`를 비워 두면 지금 사이트 주소로 QR이 자동으로 만들어져요.
다른 주소(예: 짧은 주소)로 연결하고 싶을 때만 적어 주세요.

## 고친 뒤 확인

깃허브에 저장(커밋)하고 1~2분 뒤 사이트를 새로고침하면 바뀌어요.
화면에 "내용을 불러오지 못했어요"가 뜨면 `data.json`에 쉼표나 따옴표가 빠진 곳이 있는 거예요.
